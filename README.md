# Homebrew Tap for Scalable CLI

This tap publishes the `scalable-cli` formula for the Scalable CLI.

## Install

```bash
brew tap ScalableCapital/tap
brew install scalable-cli
```

Or install directly:

```bash
brew install ScalableCapital/tap/scalable-cli
```

## Upgrade

```bash
brew update
brew upgrade scalable-cli
```

## Uninstall

```bash
brew uninstall scalable-cli
```

## What gets installed

The formula installs the macOS `Sc.app` bundle into the Homebrew Cellar and exposes the `sc` executable on your `PATH`.

## Requirements

- macOS
- Homebrew
